# Documentation

Cette documentation regroupe les elements essentiels pour comprendre, concevoir et developper le projet JobAggregator.

Elle est organisee par grandes thematiques : produit, technique et gestion de projet.

## Logique de structure

- `01_cadrage/`
  Pour comprendre le contexte, le benchmark et l'opportunite du projet.

- `01_product/`
  Pour definir le probleme, la vision, la cible et la strategie MVP.

- `02_technical/`
  Pour documenter l'architecture, les decisions backend, la data, la securite et la CI.

- `03_project/`
  Pour organiser l'execution, le backlog et les risques projet.

- `04_current_state.md`
  Pour avoir une photo factuelle de l'etat reel du repository, du code actif, des prototypes et des incoherences actuelles.
